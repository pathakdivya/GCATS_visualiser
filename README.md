# GCATS_visualiser

A simple browser page for selecting and testing either an Xbox or PlayStation controller layout for connected gamepads.
Features:
- Xbox / PlayStation selection
- Interactive thumbstick movement
- Button, D-pad, shoulder, and trigger feedback
- Browser Gamepad API support

Frontend – HTML5, CSS3, Vanilla JavaScript (no frameworks)
Hardware API – W3C Gamepad API for controller input
